# ScribeMini

A minimal macOS menu bar app for voice transcription with AI enhancement.

## Download

Get the latest release from [Releases](../../releases).

## Usage

1. **Install**: Drag ScribeMini.app to /Applications
2. **Permissions**: Grant Microphone and Accessibility when prompted
3. **Settings**: Choose your transcription provider (OpenAI or Sarvam AI)
4. **Record**: Press `Option + Space` (default hotkey), speak, release to transcribe

The transcribed text is automatically typed at your cursor position.

## Configuration

- **Transcription**: OpenAI-compatible APIs or Sarvam AI
- **AI Enhancement**: Optional post-processing (OpenAI, Anthropic, or generic hcta completion api)
- **Hotkey**: Customizable in Settings

## Requirements

- macOS 14+
- API key for your chosen transcription service
